# OpenIntM4TM2

OpenIntM4TM2 is the KLayout PDK for the IHP 130 nm IntM4TM2 aluminium back-end interposer,
a passive carrier derived from SG13G2 that keeps only the Metal4 to TopMetal2 stack.

It is a preview release, DRC and LVS are still work in progress.

## Documentation

The full documentation is at
https://ihp-open-adk-docs.readthedocs.io/en/latest/tools/05_openintm4tm2.html
